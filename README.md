Convert images between JPG, PNG, WEBP, BMP, TIFF, and AVIF in bulk. Resize, set quality, and rename in one pass - no quality loss on lossless formats.

## Features

- Supports JPG, PNG, WEBP, BMP, TIFF, GIF, and AVIF
- Resize to fixed dimensions or percentage while converting
- Set JPEG quality (1-100) per batch
- Add prefix or suffix to output filenames automatically
- Preserves folder structure in output directory

## FAQ

**Can I convert WEBP to JPG in bulk?**  
Yes, WEBP is fully supported as both input and output format.

**Does it overwrite original files?**  
No. Output always goes to a separate folder you choose.
