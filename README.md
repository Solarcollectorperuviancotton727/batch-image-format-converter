## 📚 Troubleshooting

### 🔧 Images Not Converting?
Try these solutions:
1. Ensure the images aren't open in another program
2. Check that the output folder exists and is writable
3. Verify the source images aren't corrupted (try opening them normally)
4. Restart the application and try again

### 🔍 Output Files Look Different?
Check the quality setting you selected. Lower quality settings reduce file size but may slightly alter appearance. Reset to 100% for minimal changes.

### 💾 Out of Disk Space?
Clear some space or choose a different output folder. The converter needs room for temporary files during processing.
